# Como trabalhar neste projeto (HtoGestão)

## Jeito de trabalhar com o Henrique
- **Sempre que terminar uma entrega (ou antes de começar algo grande), faça de 1 a 3 perguntas que ajudem a melhorar a ideia, a função ou o produto.** Perguntas curtas, uma por linha, cada uma dizendo por que importa. É um pedido fixo do Henrique.
- Ele não é programador e usa muito o celular: explicar em português simples, recomendar uma opção em vez de jogar a escolha, mandar links prontos.
- Mudanças vão por pull request pequeno; ele faz o merge pelo celular.
- Nunca rodar migração no banco de produção sem ele confirmar.
- Para banco, login, perfis, sincronização offline e segurança, seguir a skill `dev-app-seguro`.
